# Finzarc Assignment - Frontend Part

## Overview

A simple Task Manager App built for the Finzarc full-stack developer assignment. Users can log in, add, view, complete, and delete tasks with a clean, intuitive UI.

**Deployed App**: [https://finzarc.rahulgupta.tech/](https://finzarc.rahulgupta.tech/)

## Features

- Secure login/signup with toast notifications.
- Add, edit, delete, and mark tasks as complete.
- Monochrome UI with animations and checkbox for task completion.
- Keyboard navigation for accessibility.

## Tech Stack

- **React**: Hooks for state management.
- **React Router**: Client-side routing.
- **ShadCN/UI**: Accessible UI components.
- **Framer Motion**: Smooth animations.
- **Tailwind CSS**: monochrome styling.
- **Sonner**: Toast notifications.

## Future Scope

- Enhance mobile responsiveness.
- Add task filtering/sorting.
- Introduce dark mode.
